About the Project

Messenger App is a real-time messaging application developed as part of the Software Engineering course at the University of Cincinnati. Users can register, log in, exchange private and public messages, search for other users, manage their accounts, and view chat history. Messages are delivered instantly using WebSockets and stored in a MongoDB database, allowing users to access previous conversations. The application was developed iteratively using Scrum throughout the semester.

Implemented Features

  • Register a new user account
  • Login with a unique username
  • Logout from the application
  • Change account password
  • Find and search for users
  • Send private messages
  • Receive private messages in real time
  • Send public messages
  • Receive public messages in real time
  • Send chat interrupt notifications
  • Store public chat messages
  • Load public chat history
  • Store private chat messages
  • Load private chat history
